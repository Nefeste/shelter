# Как устроено «Наготове»

Expo SDK 57, React Native, TypeScript (ADR студии 0003). Игра целиком на телефоне: сети и сервера
нет ([`03-server-api.md`](03-server-api.md)). Здесь — слои, кто от кого зависит и почему так.

## 1. Слои

```
content/*.yaml ──(tools/content/build.ts)──► src/content/generated/bundle.json
                                                     │
                                src/content ◄────────┘  типы и загрузка содержания
                                     │
                                src/engine              чистый расчёт: подготовка, дни, разбор
                                     │
                                src/state               партия, сохранение, настройки
                                     │
                    src/screens · src/ui · src/audio · src/i18n
                                     │
                                  App.tsx               переключатель экранов, «Назад»
```

Зависимости идут только вниз по схеме: движок не знает ни React, ни экранов; экраны не считают
сами, а спрашивают движок.

| Папка | Что | Чего там нет |
|---|---|---|
| `content/` | беды, решения, товары, магазины, сценарий, источники — YAML ([`09-content.md`](09-content.md)) | кода |
| `src/content/` | типы записей (`types.ts`) и собранный пакет (`generated/`, не в git) | правил |
| `src/engine/` | `prep.ts` — подготовка; `days.ts` — расчёт дней и звёзды; `review.ts` — разбор и источник строки; `core/` — зерно и хеш | React, `Date`, `Math.random`, дробей в состоянии |
| `src/state/` | `game.ts` — партия как хук React; `run.ts` — упаковка сохранения; `storage.ts` — AsyncStorage; `checklist.ts` — «Мой список» по разделам с суммами; `voices.ts` — какая реплика семьи к какому поводу; `radio.ts` — слышно ли радио; `pantry.ts` — чем занята кладовая; `scene.ts` — что в окнах соседей | расчёта |
| `src/screens/` | первый экран, вводная, подготовка, дни, итог, «Об игре» | текстов (они в `src/i18n`) |
| `src/ui/` | кнопки и карточки (`kit.tsx`), шрифты студии (`fonts.ts`), токены бренда (`theme.ts`, копия `brand/tokens.css` устава), рисунки (`Scene.tsx`, `House.tsx`, `icons.tsx`, `Snow.tsx`), реплика семьи (`Bubble.tsx`), кладовая (`Pantry.tsx`) | — |
| `src/audio/` | `sound.ts` — звуки и петли через `expo-audio` | — |
| `src/i18n/` | все строки для игрока | — |
| `src/version.ts` | номер версии для «Об игре» | — |
| `assets/audio/` | звуки, собранные `npm run sound` | записей со стороны |
| `plugins/` | подпись релиза и вырезание `INTERNET` из релизного манифеста | — |
| `tools/` | сборка содержания, тесты, сценарий в браузере, «виртуальный игрок», синтез звука | — |

## 2. Движок

**Чистый и детерминированный** (ADR студии 0004). Команда подготовки — функция «состояние →
новое состояние или отказ» (`choose`, `nextDay`); состояние не меняется на месте. Расчёт событий —
функция «подготовка, зерно → исход» (`runDays`). Целые числа: рубли, минуты, литры, децилитры
воды, килокалории, градусы. Случайность — только `Rng` из `core/rng.ts` с именованными ветвями
(`days`, `thaw`, `risk:<беда>`), зерно — номер попытки. Поэтому:

- сохранение — это выборы, а не результат: исход пересчитывается тем же движком;
- тест и «виртуальный игрок» получают те же 14 дней, что игрок на телефоне;
- отказ (`PrepError`: денег, часов, места нет, беда закрыта) — значение, а не исключение для
  экрана: экран сначала спрашивает `canChoose` и показывает причину словами.

`World` — обёртка над пакетом содержания с поиском по id; движок получает её аргументом и не
читает файлы.

## 3. Содержание

Записи пишутся в `content/`, собираются и проверяются `tools/content/build.ts` в
`src/content/generated/bundle.json`; сборка останавливается на любой ошибке: нет источника,
марка или магазин в тексте, доза, латиница, не четыре решения у беды, ссылка на несуществующую
запись ([`09-content.md`](09-content.md)). Собранный пакет не хранится в git: его собирают
`npm run content`, `npm test`, `npm run typecheck`, `npm run export:web` и CI.

## 4. Состояние и сохранение

`useGame` (`src/state/game.ts`) держит экран, подготовку, номер попытки и фазу партии. Каждое
изменение сохраняется в AsyncStorage строкой (`run.ts`); при запуске сохранение разбирается и
проверяется по содержанию — если решения с тех пор исчезли, партия начинается заново. Исход 14
дней не сохраняется — он пересчитывается. Формат — [`04-data-model.md`](04-data-model.md#3-сохранение).

## 5. Экраны

Экранов шесть, и игра — живой объект партии, поэтому без Expo Router: `App.tsx` переключает
экран по состоянию и обрабатывает «Назад» — на первый экран, с первого — выход. Карточка беды
закрывается «Назад» сама. Подтверждение («Начать заново?») — карточка на самом экране, не
системный `Alert` (устав, `05-rules.md`).

Все строки — `T.<раздел>.<ключ>` из `src/i18n`; тест не пускает кириллицу в строки кода вне этой
папки и `content/`.

## 6. Рисунок и звук

- `react-native-svg`: сцена дня и итога — одна картинка из прямоугольников и многоугольников
  шириной 320 по центру, земля и небо — на всю ширину. Снег и дым — `Animated` с родным
  драйвером: дёшево на недорогом телефоне.
- `expo-audio`: короткие звуки — по одному плееру на звук, петли (ветер, печь) — свои плееры с
  громкостью. Звук смешивается с чужой музыкой, в фоне не играет; микрофона нет.
- Звуки — синтез `tools/sound/gen.ts` (основа — из «Сказов»), тест сверяет файлы с синтезом
  байт в байт.

## 7. Сборка

- **APK** — `.github/workflows/android.yml` по тегу `vX.Y.Z`: `expo prebuild`, Gradle на две
  архитектуры (arm64-v8a, armeabi-v7a), подпись постоянным ключом, проверки набора
  `gornitsa-kit` (подпись, разрешения, без сети, 16 КБ, размер ≤ 40 МБ) — [`05-process.md`](05-process.md).
- **Нативные библиотеки в APK сжаты** (`expo-build-properties`, `useLegacyPackaging`): около
  24 МБ вместо 42; при установке они распаковываются.
- **Без сети в релизе:** `plugins/with-release-no-internet.js` убирает `INTERNET`; лишние
  разрешения библиотек — `blockedPermissions` в `app.json`; список разрешённых —
  `.github/apk-permissions.txt` (путь владельца).
- **Веб-сборка** (`npm run export:web`) — только для сценария в браузере, не выпускается.

## 8. Бюджет

Пределы — спецификация прототипа, раздел 8: кадр, расчёт 14 дней ≤ 50 мс на телефоне, холодный
запуск ≤ 3 с, APK ≤ 40 МБ. Замеры на телефоне — ещё не сделаны (STATUS).

повод перенести его и на ту сторону.
