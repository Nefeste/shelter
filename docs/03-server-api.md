# Сервер

Сервера у «Убежища» нет. Игра работает целиком на телефоне и ничего не отправляет: ни
статистики, ни отчётов о сбоях, ни сохранений (ADR студии 0005 и 0008). В релизном APK нет
разрешения `INTERNET` — это проверяет сборка ([`05-process.md`](05-process.md#сборка-apk)).

Если сервер понадобится (облачная копия, своя статистика), сначала — решение владельца и ADR
проекта, потом этот документ.
