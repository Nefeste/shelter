# Документы «Убежища»

Правила студии — только в уставе `Nefeste/gornitsa`; здесь — то, что своё у этой игры. Как
пишутся документы и спецификации — устав, [`docs/04-process.md`](https://github.com/Nefeste/gornitsa/blob/main/docs/04-process.md).
Где проект сейчас — [`../STATUS.md`](../STATUS.md).

Читать по порядку:

1. [`01-product.md`](01-product.md) — что обещаем игроку, чего нет сознательно, словарь.
2. [`08-game-design.md`](08-game-design.md) — игра, какой она выйдет в 1.0: уровень, подготовка,
   расчёт дней, звёзды, разбор, экраны, сценарии; числа правил.
3. [`09-content.md`](09-content.md) — беды, решения, товары, цены: откуда факты и чего в текстах
   нет. **Читать до любой записи в `content/`.**
4. [`02-architecture.md`](02-architecture.md), [`03-server-api.md`](03-server-api.md) (сервера
   нет), [`04-data-model.md`](04-data-model.md) — как устроено.
5. [`05-process.md`](05-process.md), [`06-testing.md`](06-testing.md) — версии, ветки, сборка,
   выпуск; что запускать перед «готово».
6. [`07-roadmap.md`](07-roadmap.md) — этапы, что осталось в прототипе, линейка сценариев,
   решения владельца.
7. [`specs/2026-11-prototype.md`](specs/2026-11-prototype.md) — живая спецификация прототипа:
   критерии, решения агента, журнал проверок.
8. [`10-money.md`](10-money.md), [`11-market.md`](11-market.md) — деньги и рынок.
9. [`adr/`](adr/) — решения, которые дорого менять; [`adr/0001-studio-adrs.md`](adr/0001-studio-adrs.md)
   — как здесь применяются ADR студии.
10. [`reports/`](reports/) — отчёты, которые собирает код: [`2026-11-virtual-player.md`](reports/2026-11-virtual-player.md)
    — «виртуальный игрок», все сочетания решений (`npm run sim`; руками не править).
11. [`journal/`](journal/) — журнал по месяцам: [`2026-11.md`](journal/2026-11.md).

Замысел и решения владельца, из которых выросла игра, — `Nefeste/uprava`,
`plan/reserve-2026-11.md`, раздел 6.

**Одно место для факта.** Число записи (цена, литры, нормы, деньги сценария) — только в
`content/`; число правила (дни до эвакуации, звёзды) — в `08-game-design.md`; состояние — только в
`STATUS.md`. Остальные документы ссылаются, а не повторяют.
