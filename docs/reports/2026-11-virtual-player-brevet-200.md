# Отчёт «виртуального игрока»: «Бревет 200 км»

Собран `bun tools/sim/player.ts` (перебор детерминирован: тот же код и то же содержание — тот же отчёт): 4 096 сочетаний решений, четыре привычки порядка, зёрна 1…30 (в игре зерно — номер попытки).

Сочетание — по одному решению на каждую из начальных бед (6) и на беды, которые создали выбранные решения (нет). Звёзды — как в игре: 1 — проехали все 4 этапов без схода, 2 — без ловушек, без жажды, голода, холодной ночи и клеща, 3 — ни одного трудного этапа.

## 1. Сколько звёзд

Доля пар «сочетание × зерно». «Не собрать» — привычка не смогла выбрать всё задуманное: не хватило денег, часов или места.

|---|---|---|---|---|---|
| «по списку» | 6,3 % | 69,1 % | 21,2 % | 1,3 % | 2,1 % |
| «с расчётом» | 6,3 % | 69,1 % | 21,2 % | 1,3 % | 2,1 % |
| «наоборот» | 6,3 % | 70,2 % | 20,4 % | 1,2 % | 1,9 % |
| «дёшево, потом лучше» | 9,7 % | 69,8 % | 18,0 % | 1,0 % | 1,5 % |

Три звезды хоть на одном зерне — 248 сочетаний; на всех зёрнах хоть одной привычкой — 7.

## 2. Критерии спецификации

| Критерий | Итог | Выполнен |
|---|---|---|
| Три звезды достижимы | 248 сочетаний | да |
| «Всё дешёвое» — сход с маршрута или одна звезда | лучшее — 1 ★ | да |
| Нет решения, которое лучше всех во всех сочетаниях | такого нет | да |
| Ни одна ловушка не даёт три звезды | лучшее с ловушкой — 1 ★ | да |

«Лучше всех» — решение беды, которое при любых решениях остальных бед даёт не меньше звёзд, чем любое другое решение этой беды, а где-то больше (звёзды — среднее по зёрнам, лучшая из привычек; созданные беды — лучшим для них решением).
