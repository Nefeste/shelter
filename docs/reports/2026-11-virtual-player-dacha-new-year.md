# Отчёт «виртуального игрока»: «Новогодние на даче»

Собран `bun tools/sim/player.ts` (перебор детерминирован: тот же код и то же содержание — тот же отчёт): 448 сочетаний решений, четыре привычки порядка, зёрна 1…30 (в игре зерно — номер попытки).

Сочетание — по одному решению на каждую из начальных бед (4) и на беды, которые создали выбранные решения («Угарный газ»). Звёзды — как в игре: 1 — продержались все 5 дней, 2 — без ловушек и без дней без питья, еды и тепла, 3 — ни одного дня, когда чего-то не хватало.

## 2. Критерии спецификации

| Критерий | Итог | Выполнен |
|---|---|---|
| Три звезды достижимы | 18 сочетаний | да |
| «Всё дешёвое» — эвакуация или одна звезда | лучшее — 0 ★ | да |
| Нет решения, которое лучше всех во всех сочетаниях | такого нет | да |
| Ни одна ловушка не даёт три звезды | лучшее с ловушкой — 1 ★ | да |

«Лучше всех» — решение беды, которое при любых решениях остальных бед даёт не меньше звёзд, чем любое другое решение этой беды, а где-то больше (звёзды — среднее по зёрнам, лучшая из привычек; созданные беды — лучшим для них решением).
