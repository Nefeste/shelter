# Отчёт «виртуального игрока»: «Велопоход выходного дня»

Собран `bun tools/sim/player.ts` (перебор детерминирован: тот же код и то же содержание — тот же отчёт): 65 536 сочетаний решений, четыре привычки порядка, зёрна 1…30 (в игре зерно — номер попытки).

Сочетание — по одному решению на каждую из начальных бед (8) и на беды, которые создали выбранные решения (нет). Звёзды — как в игре: 1 — проехали все 5 этапов без схода, 2 — без ловушек, без жажды, голода, холодной ночи и клеща, 3 — ни одного трудного этапа.

«Лучше всех» — решение беды, которое при любых решениях остальных бед даёт не меньше звёзд, чем любое другое решение этой беды, а где-то больше (звёзды — среднее по зёрнам, лучшая из привычек; созданные беды — лучшим для них решением).
