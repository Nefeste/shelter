# Отчёт «виртуального игрока»: «Ледяной дождь»

Собран `bun tools/sim/player.ts` (перебор детерминирован: тот же код и то же содержание — тот же отчёт): 77 824 сочетаний решений, четыре привычки порядка, зёрна 1…10 (в игре зерно — номер попытки).

Сочетание — по одному решению на каждую из семи начальных бед и на беды, которые создали выбранные решения («угарный газ» — от обогревателя, печи и машины в гараже; «пожар» — от свечей). Звёзды — как в игре: 1 — продержались 14 дней дома, 2 — без ловушек и без дней без питья, еды и тепла, 3 — ни одного дня, когда чего-то не хватало.

## 2. Критерии спецификации

| Критерий | Итог | Выполнен |
|---|---|---|
| Три звезды достижимы | 22 сочетаний | да |
| «Всё дешёвое» — эвакуация или одна звезда | лучшее — 0 ★ | да |
| Нет решения, которое лучше всех во всех сочетаниях | «Печь с дымоходом и дрова», «Запас по калориям на 14 дней», «Свечи», «Запас по рецепту на две недели», «Подставки, присмотр и огнетушитель» | **нет** |
| Ни одна ловушка не даёт три звезды | лучшее с ловушкой — 1 ★ | да |

«Лучше всех» — решение беды, которое при любых решениях остальных бед даёт не меньше звёзд, чем любое другое решение этой беды, а где-то больше (звёзды — среднее по зёрнам, лучшая из привычек; созданные беды — лучшим для них решением).
