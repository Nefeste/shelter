# 0001. Какие ADR студии действуют здесь и как

Общие решения — в уставе, `adr/` (https://github.com/Nefeste/gornitsa/tree/main/adr); здесь они
не пересказываются, только как применены.

| ADR студии | Здесь |
|---|---|
| 0002 — код копируется с пометкой источника | случайность, хеш, звук и проверка текстов — из «Сказов», подпись релиза и номер версии — из «Нард», релиз без сети — из «Анамнеза»; список — [`02-architecture.md`](../02-architecture.md#9-что-скопировано-из-игр-студии) |
| 0003, 0019 — Expo, нативные папки генерируются, CI на PR, APK только на тег | Expo SDK 57; `pr.yml` на каждом PR, `android.yml` только по тегу — [`05-process.md`](../05-process.md) |
| 0004 — чистый детерминированный движок | `src/engine/`, целые числа, зерно; сохранение — снимок с версией |
| 0005 — без сети по умолчанию | игра работает целиком без сети; сервера нет |
| 0006 — постоянный идентификатор и ключ | `games.gornitsa.shelter` (решение владельца 01.11.2026, тест держит его); APK подписан постоянным ключом с 0.1.1 |
| 0008 — данные минимум | игра ничего не отправляет; своя статистика — только если решит владелец |
| 0009 — деньги не покупают преимущество | решение о деньгах — до выпуска, варианты — [`10-money.md`](../10-money.md); в прототипе денег нет |
| 0010 — без давления | игровое время вместо настоящего; ни энергии, ни серий |
| 0012 — контент из названных источников | каждый факт и товар — с источником и `review: draft` |
| 0017 — видимость | репозиторий закрыт |
| 0018 — права по классам | пути владельца — в `.github/CODEOWNERS` |
| 0022 — набор `gornitsa-kit` | CI, подпись, проверки APK и загрузка в RuStore — из набора; RuStore Pay — оттуда же, если будут покупки |
| 0023 — графика | рисунок — 2D кодом, моделей и генераторов нет; цель кадра — на современном телефоне (модель — #18); «меньше движения» на первом экране, вибрации нет; пробелы — своих цветов в рисунках, лист стиля — с новым видом после прототипа: [`02-architecture.md`, §10](../02-architecture.md#10-графика-adr-0023-устава) |
