# 0001. Какие ADR студии действуют здесь и как

Общие решения — в уставе, `adr/` (https://github.com/Nefeste/gornitsa/tree/main/adr); здесь они
не пересказываются, только как применены.

| ADR студии | Здесь |
|---|---|
| 0002 — код копируется с пометкой источника | диалог, тексты, журнал сбоев и настройки — из «Вотчины»; сборка содержания и случайность — из «Сказов» (спецификация прототипа, раздел 2) |
| 0003, 0019 — Expo, нативные папки генерируются, CI на PR, APK только на тег | Expo SDK 57, как у остальных игр; CI — с первым кодом |
| 0004 — чистый детерминированный движок | `src/engine/`, целые числа, зерно; сохранение — снимок с версией |
| 0005 — без сети по умолчанию | игра работает целиком без сети; сервера нет |
| 0006 — постоянный идентификатор и ключ | предложение `games.gornitsa.shelter` — решает владелец до первой сборки |
| 0008 — данные минимум | игра ничего не отправляет; своя статистика — только если решит владелец |
| 0009 — деньги не покупают преимущество | решение о деньгах — до выпуска; в прототипе денег нет |
| 0010 — без давления | игровое время вместо настоящего; ни энергии, ни серий |
| 0012 — контент из названных источников | каждый факт и товар — с источником и `review: draft` |
| 0017 — видимость | репозиторий закрыт |
| 0018 — права по классам | пути владельца — в `.github/CODEOWNERS` |
| 0022 — набор `gornitsa-kit` | CI, подпись, проверки APK и загрузка в RuStore — из набора; RuStore Pay — оттуда же, если будут покупки |
