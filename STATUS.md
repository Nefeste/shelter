# Состояние «Наготове»

**Версия:** 0.9.0 — второй сценарий «Новогодние на даче» (первый из «Сборов в дорогу»), выбор сценария на первом экране. Последний APK — 0.8.0.

**Стадия:** прототип ([`docs/specs/2026-11-prototype.md`](docs/specs/2026-11-prototype.md)). Два
сценария: «Ледяной дождь» и «Новогодние на даче» ([`docs/specs/2026-11-trips.md`](docs/specs/2026-11-trips.md));
движок, содержание с источниками, тесты, сценарий в браузере, «виртуальный игрок», CI из
`gornitsa-kit`. Идентификатор — `games.gornitsa.shelter`.

**Что дальше:** велопоход выходного дня по спецификации [`docs/specs/2026-11-bike-weekend.md`](docs/specs/2026-11-bike-weekend.md)

**Документы:** полный комплект — [`docs/README.md`](docs/README.md); игра целиком —
[`docs/08-game-design.md`](docs/08-game-design.md).
