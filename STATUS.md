# Состояние «Убежища»

**Версия:** 0.3.0 — третья звезда за «всего хватило на 14 дней», источник у каждой строки разбора, отчёт «виртуального игрока». Последний собранный APK — 0.1.1; 0.2.0 остановилась на пределе размера, исправлено в 0.2.1 (сжатые библиотеки, около 24 МБ).

**Стадия:** прототип ([`docs/specs/2026-11-prototype.md`](docs/specs/2026-11-prototype.md)). Каркас:
сценарий «Ледяной дождь» проходится целиком — подготовка, 14 дней, итог; движок, содержание,
тесты, сценарий в браузере, CI из `gornitsa-kit`. Идентификатор — `games.gornitsa.shelter`
(решение владельца 01.11.2026).

**Что дальше:** перебор («виртуальный игрок», `npm run sim`, [отчёт](docs/reports/2026-11-virtual-player.md))
показал, что пять решений лучше остальных при любых других — нужны настоящие развилки: обогреватель
и еда попроще должны хоть где-то давать дом без холода и голода; свечам — остаток риска пожара даже
с присмотром; аптечке — своя польза (событие «насморк у ребёнка» из спецификации). Каждое число — с
источником или как допущение. Затем — остаток «Жизни мира», замеры на телефоне, игра владельца.

**Ждёт владельца:**
- сверить семь цен Росстата (сентябрь 2026) с файлом https://rosstat.gov.ru/storage/mediabank/sred_potreb_cen_09-2026.xlsx — из среды агента он не скачивается, числа взяты с зеркала;
- слить PR размера APK (`app.json` — ваш путь), затем PR «виртуального игрока» (0.3.0, тоже `app.json`); тег — `v0.3.0` (или `v0.2.1` после первого, чтобы проверить размер раньше);
- до выпуска — название в магазине (ФИПС), деньги, рейтинг для ядерного уровня.
