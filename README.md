# Убежище

Маленькая игра студии «Горница» для телефона: как подготовиться к чрезвычайной ситуации.
Уровень — цепочка «беда → решение → новая беда». На каждую беду четыре решения: дешёвое,
среднее, правильное и ловушка. Деньги, часы и место ограничены; дешёвое можно улучшить позже,
а порядок важен. Потом — 14 дней расчётом и честный разбор: что сработало и чего не хватило.
Всё, что продаётся в игре, можно купить в обычном магазине; каждый факт — из названного
источника.

- Состояние — [`STATUS.md`](STATUS.md).
- Документы — [`docs/`](docs/README.md).
- Живая спецификация — [`docs/specs/2026-11-prototype.md`](docs/specs/2026-11-prototype.md).

## Как запустить

```bash
npm ci
npm run content                       # собрать и проверить содержание
npx expo start                        # приложение
npm run typecheck && npm run lint && npm test
EXPO_OFFLINE=1 npm run export:web && npm run e2e   # сценарий в браузере, снимки — tools/e2e/out/
```

## Версии

### 0.2.0 — рисунки и звук

- 14 дней видно: дом под снегом и ледяным дождём, провода во льду, свет в окне, пока есть чем светить, дым из трубы, если топится печь. Семья в окне укутана, когда в доме холодно; ночью небо темнеет.
- У каждой беды своя иконка; запас воды, еды и света — полосками, красными, когда остаётся меньше пятой части.
- На итоге — дом: все дома и тихо или пустой дом, если семья уехала.
- Звук: ветер и ледяной дождь, треск печи, щелчок, выбор решения, новый день, итог. Все звуки собраны своим кодом, чужих записей нет. Выключается на первом экране.

### 0.1.2 — «Назад» не теряет подготовку

- «Назад» на телефоне ведёт на первый экран, а выбранное в подготовке сохраняется: там — «Продолжить». Карточку беды «Назад» просто закрывает.
- Начатая игра сохраняется и после закрытия приложения; «Начать заново» — только после подтверждения.
- Цены и факты — из названных источников, числа без источника перечислены в «Об игре» как допущения игры.

### 0.1.1 — сборка без лишнего разрешения

- Игра больше не просит разрешение на вибрацию: она его не использует.

### 0.1.0 — каркас прототипа

- Сценарий «Ледяной дождь»: три дня подготовки, девять бед по четыре решения, 14 дней расчётом,
  разбор и «Мой список». Все факты — черновики; что ещё не сверено с источником, помечено.
