# Убежище

Маленькая игра студии «Горница» для телефона: как подготовиться к чрезвычайной ситуации.
Уровень — цепочка «беда → решение → новая беда». На каждую беду четыре решения: дешёвое,
среднее, правильное и ловушка. Деньги, часы и место ограничены; дешёвое можно улучшить позже,
а порядок важен. Потом — 14 дней расчётом и честный разбор: что сработало и чего не хватило.
Всё, что продаётся в игре, можно купить в обычном магазине; каждый факт — из названного
источника.
