# Звуки «Наготове»: откуда каждый файл

Все файлы — **синтез**, собраны `npm run sound` (`tools/sound/gen.ts`) из формул; чужих записей нет.
Пересобрать — та же команда: шум берётся из генератора игры с постоянным зерном, файлы выходят те же
байт в байт. Руками не править.

Общее: моно, 22050 Гц, 16 бит. Петли сведены без шва.

| Файл | Что | Параметры |
|---|---|---|
| `storm.wav` | ветер и ледяной дождь — петля 6 с | шум 300–1500 Гц, порывы 2.1 и 3.7 с; щелчки льда 9/с около 3200 Гц |
| `crackle.wav` | треск печи — петля 4 с | гул 250–700 Гц, всплески 1,2–3,6 кГц, 6/с |
| `tap.wav` | щелчок кнопки | шум в полосе 2 кГц, 30 мс |
| `click.wav` | щелчок фонаря в сумерки | два щелчка около 3600 Гц, второй через 45 мс и тише |
| `choose.wav` | решение выбрано | 660 и 880 Гц, затухание 60–70 мс |
| `day.wav` | новый день события | 520 Гц, затухание 70 мс |
| `done.wav` | итог: все дома | до-ми-соль-до, перебор 120 мс |
| `evac.wav` | итог: эвакуация | до и ля вниз, мягко |
